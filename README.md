# math-power-study

『수학의 힘』 깊이 읽기: 장별 학습 사이트 (GitHub Pages)

**사이트 주소:** https://dreamdaddy80.github.io/math-power-study/

> 『수학의 힘』(원서: Oliver Johnson, *Numbercrunch*, 2023 추정)을 바탕으로 한 **개인 학습 노트**입니다.
> 책의 문장은 길게 옮기지 않고 학습자의 말로 풀어 썼으며(직접 인용은 한두 문장 이내), 그래프와 도식은 모두 직접 만들었습니다. 책의 그림은 복제하지 않았습니다.

## 무엇이 들어 있나

- **홈**: 책 한눈에 보기, 3가지 도구(구조·무작위성·정보) 지도, 4부 13장 학습 로드맵, 장별 완료 체크(브라우저 localStorage에 저장)
- **1~13장 모듈**: 장마다 같은 틀
  1. 이 장의 질문 2. 3줄 핵심 3. 절별 깊이 읽기(개념 → 책의 사례·숫자 → 왜 그런가 → 흔한 오해) 4. 쉬운 비유 5. 수식 풀이(기호별 설명) 6. 인터랙티브 체험 7. HR·실무 적용 8. 확인 퀴즈(즉시 채점·해설) 9. 용어 카드
- **인터랙티브 체험 26종**: y축 자르기 착시, 6차 다항식 과적합 외삽, 페르미 추정, 1인당 환산, 선형 vs 지수 + 로그스케일, SIR 시뮬레이터, 대수의 법칙, 중심극한정리, 앤스컴 콰르텟, p-해킹, 신뢰구간, 베이즈 검사 계산기, 채용 퍼널 진단, 승산↔확률 변환, 로지스틱 플롯, 엔트로피·켈리, 집단검사 최적화, 랜덤워크, 나이트 랜덤워크, 생일 문제, 연속 패턴, 요일 효과·이동평균, 레버 게임 미니맥스, 가위바위보 대결, U자 손해 곡선, 오류 체크리스트
- **전체 용어 사전**(검색·도구별 필터), **13장 오류 체크리스트**, **전체 복습 퀴즈**(전 장 무작위 15문항), **장 간 연결 맵**
- 해시 라우팅(`#ch1` ~ `#ch13`, `#glossary`, `#checklist`, `#review`, `#map`)으로 장별 링크 공유 가능

## 기술

- 단일 `index.html` (외부 라이브러리·폰트·CDN 없음, 오프라인 동작)
- 모바일·데스크톱 반응형, 라이트/다크 모드(시스템 설정 + 수동 전환)
- 그래프는 모두 인라인 SVG로 직접 그림

## 내용 원칙과 검증

- 원본: Gemini Notebook으로 추출한 장별 노트. 추출 과정에서 깨진 수식(위첨자, 분수, 아래첨자)은 복원했고, 의심스러운 숫자는 원본 스캔 PDF와 대조했습니다. 사이트 안에는 바로잡은 곳마다 "PDF 대조 메모"를 달았습니다.
- 각 장의 **HR·실무 적용**과 가상 예시 숫자는 학습자가 덧붙인 것으로 책의 내용이 아닙니다.
- 진도·체크 상태는 방문자 브라우저에만 저장되며 서버로 전송되지 않습니다.
